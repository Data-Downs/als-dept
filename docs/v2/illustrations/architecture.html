Architectural enforcement point
Architectural rules enforced
  • All LLM calls route through @als/adapters — zero direct Anthropic SDK usage elsewhere
  • All service calls route through CapabilityInvoker in @als/runtime — single choke point
  • Legibility Studio fetches evidence from Citizen app API via HTTP — it does not import @als/evidence directly
