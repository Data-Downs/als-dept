Key Insights

  • Universal Fields (8/8 personas): Full Name, DOB, Address, and NI Number are needed by every persona. Once verified by one source, these can be reused across all services.
  • High Reuse (7/8 personas): Employment and income data spans nearly all personas except immigration, representing a major opportunity for cross-service data sharing through HMRC.
  • Medium Reuse (6/8 personas): Benefits status is critical for most personas but notably not for self-employed or first-time workers.
  • Specialized Data (2-3/8 personas): Children records, EHCP details, and immigration status are persona-specific but represent deep data dependencies when required.
  • Data Efficiency: Agents can dramatically reduce form-filling burden by prefilling the ~25 universal and commonly-reused fields, asking users only for persona-specific data.
