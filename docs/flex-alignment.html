FLEX / UDP + ALS

Where the agent layer meets the pipes

GDS is building FLEX (the secure gateway) and UDP (the citizen data store) to connect the GOV.UK app to department services. The Agentic Legibility Stack is the intelligence layer that sits on top — turning those pipes into a joined-up, consent-driven citizen experience.

01 — The infrastructure

What the Flex team is building

FLEX and UDP are two new platforms, being built by GDS and DSIT right now, that give the GOV.UK app a secure, structured way to reach department data on behalf of a citizen.

FLEX

Public integration layer
  • Three-tier gateway: public front door, private business rules, and a future service connector
  • Departments build “domain modules” that slot into each tier (DVLA, DWP, etc.)
  • Authenticates, rate-limits, and routes — the private gateway never touches the public internet
  • Currently live in dev/staging; Notifications is the first consumer

UDP

User Data Platform
  • Central, consent-gated store of citizen data linked to One Login identity
  • Not sharing data across government — bringing it together at the citizen’s request
  • Accessed only over private tunnel, never exposed publicly
  • Currently stores notification preferences; DVLA ID linking in progress

02 — The full picture

Add the agent layer on top

FLEX provides the secure pipes. ALS adds the intelligence: an AI agent that understands the citizen’s situation, manages consent, orchestrates across departments, and leaves an auditable trail.

The full picture: ALS provides the agent intelligence layer; FLEX provides the secure infrastructure; departments provide the data

ALS — agent layer
FLEX — GDS platform
UDP — data store
Key point

FLEX and ALS are complementary, not competing. FLEX is the plumbing — how data moves securely between departments and the app. ALS is the intelligent front-of-house — how an AI agent uses those pipes on behalf of a citizen, with consent, transparency, and multi-service orchestration. Today ALS simulates what FLEX will provide for real.

04 — What ALS adds

Capabilities that sit above the pipes

FLEX gives the app a way to reach departments securely. ALS adds the capabilities that turn individual API calls into a joined-up experience.

What Flex does that ALS doesn’t

FLEX handles real authentication against One Login, enforces rate limits, manages TLS termination, routes across the private network, and is going through formal IT Health Checks. These are production security concerns that ALS delegates to FLEX rather than reimplementing.

05 — Concept-by-concept alignment

Side by side

Every major FLEX/UDP concept has a direct counterpart in ALS. Neither system duplicates the other — they layer.

Concept FLEX / UDP ALS
Gateway Three-tier gateway (public → private → service) with department modules at each level CapabilityInvoker — single auditable choke point. In production, calls FLEX APIs
User data UDP — centralised store linked to One Login identity. Stores profile, preferences, consent Citizen Wallet — shows credentials, earned documents, consent preferences. Reads from UDP
Consent “At the consent of the user” — binary accept/decline shown in demo Standing preferences with scope hierarchy (once → service → department → cross-government), auto-resolved before citizen is asked
Dept modules Developer-built code modules that slot into gateway tiers (e.g. DVLA module) Machine-readable service manifests: policy, state model, consent model, input/output schema per service
Identity One Login (user IDs visible in demo) Persona-based identity mapped to One Login-style credentials
Business rules Private Gateway applies department-specific business logic PolicyEvaluator + StateMachine — declarative, auditable, never delegated to the AI
Multi-service Department-by-department — each module is independent Life event triage: identifies related services, deduplicates fields, orchestrates a joined-up journey
Audit Not shown in presentation Immutable append-only evidence store: every call traced with receipt, visible in Legibility Studio
AI / agents Not addressed Constrained LLM: handles language and conversation; all policy, state, and consent decisions enforced in code

The relationship

ALS prototypes the citizen experience and the department publishing model. FLEX builds the real, secure infrastructure underneath. When FLEX’s DVLA and DWP modules go live, ALS’s CapabilityInvoker simply points at real FLEX endpoints instead of simulated responses. The experience layer stays the same — the pipes become real.
